# บทเรียน Backend ระบบประเมินบุคลากร

บทเรียนแบบโต้ตอบสำหรับเรียนรู้ backend ของระบบประเมินบุคลากร (Node.js, Express, MySQL) โดยอ่านจากโค้ดจริงทีละไฟล์และทีละบรรทัด ไม่ต้องติดตั้งอะไรเพิ่ม เปิดไฟล์ HTML ในเบราว์เซอร์ได้ทันที

## เปิดใช้งาน

1. ดาวน์โหลดไฟล์ `backend-lessons.html`
2. ดับเบิลคลิกเพื่อเปิดในเบราว์เซอร์ (Chrome, Edge หรือ Firefox)

ไม่ต้องรันเซิร์ฟเวอร์ และไม่ต้องต่อฐานข้อมูล ทุกอย่างทำงานในเบราว์เซอร์

## เนื้อหาทั้ง 8 บท

| บท | หัวข้อ | ไฟล์ที่อ่านในบท |
|---|---|---|
| 1 | ออกแบบฐานข้อมูล | `schema.sql` |
| 2 | เชื่อมต่อฐานข้อมูล เซิร์ฟเวอร์ และฟังก์ชันช่วย | `db.js`, `server.js`, `helpers.js` |
| 3 | ยืนยันตัวตนและสิทธิ์ | `auth.js`, `routes/auth.js` |
| 4 | จัดการข้อมูลหลัก (admin) | `routes/periods.js`, `topics.js`, `indicators.js`, `assignments.js`, `users.js` |
| 5 | การประเมินตนเองและการอัปโหลด | `routes/self.js`, `upload.js`, `routes/files.js` |
| 6 | กรรมการให้คะแนนและการคำนวณ | `routes/evaluate.js` |
| 7 | รายงานและการสำรองข้อมูล | `routes/reports.js`, `routes/backup.js` |
| 8 | การทดสอบ seed และ package.json | `seed.js`, `tests/*.test.js`, `package.json` |

แต่ละบทมีลำดับการเรียนดังนี้

1. **เนื้อหาการสอน** อธิบายแนวคิดก่อนดูโค้ด
2. **อ่านโค้ดจริงทีละบรรทัด** แต่ละบรรทัดมีคำแปลภาษาพูดกำกับ
3. **แบบทดสอบความเข้าใจ** ต้องตอบถูกทุกข้อ แบบฝึกพิมพ์โค้ดของบทนั้นจึงจะเปิด
4. **แบบฝึกพิมพ์โค้ด** พิมพ์โค้ดของแต่ละช่วงบรรทัดด้วยตนเอง แล้วกดตรวจ ระบบจะชี้บรรทัดที่ต่างกันและบอกคำที่อาจพิมพ์ผิด

## ฟีเจอร์

- **สารบัญ (sidebar)** กระโดดไปยังบทและไฟล์ที่ต้องการ พร้อมแถบความคืบหน้าของแต่ละบท
- **พจนานุกรม** รวมศัพท์และรูปแบบที่พบในโค้ด (JavaScript, Express, SQL, HTTP) ค้นหาได้
- **ตัวจำลอง cascade** ดูว่าการลบแถวหนึ่งจะลบตารางลูกใดบ้างตาม FOREIGN KEY
- **ตัวคำนวณคะแนน** ลองให้คะแนนตัวชี้วัดตัวอย่างและดูผลร้อยละตามสูตรในระบบจริง
- **ตัวแก้โค้ดในช่องพิมพ์** มีเลขบรรทัด Tab เยื้องทั้งบล็อก Shift+Tab ถอนการเยื้อง และ Enter ย่อหน้าตามบรรทัดก่อนหน้า
- **คอมเมนต์ไม่บังคับ** ค่าเริ่มต้นไม่ต้องพิมพ์คอมเมนต์ตรงทุกตัวอักษร เปลี่ยนเป็นบังคับได้จากแผงตั้งค่า
- **บันทึกความคืบหน้า** ผลการทำแบบฝึกและร่างโค้ดเก็บไว้ในเบราว์เซอร์ รีเฟรชแล้วไม่หาย
- **แผงตั้งค่า** เปิดหรือปิดพื้นหลัง Matrix rain เลือกโหมดแสดงผล (อัตโนมัติ สว่าง มืด) และล้างความคืบหน้า
- **Ctrl+Enter** ในช่องพิมพ์โค้ดเพื่อตรวจคำตอบทันที

## ข้อควรรู้

- ไฟล์นี้ฝังโค้ดจาก backend ของโปรเจกต์ไว้ทั้งหมดเพื่อใช้แสดงและตรวจคำตอบ
- `seed.js` มีรหัสผ่านตัวอย่างของผู้ใช้ทดสอบ และ `auth.js` มีค่า `JWT_SECRET` สำรองในโค้ด ถ้านำแนวทางนี้ไปใช้จริงต้องเปลี่ยนค่าเหล่านี้ก่อน
- ความคืบหน้าเก็บในเบราว์เซอร์ของผู้ใช้แต่ละคน ไม่ได้ส่งไปที่ใด
- บรรทัดอ้างอิงตรงกับโค้ด ณ ตอนสร้างบทเรียน ถ้าโค้ดต้นฉบับเปลี่ยน เนื้อหาบางส่วนอาจไม่ตรงกัน

## ทดสอบบนเครื่องที่ใช้

- Chrome, Edge และ Firefox รุ่นล่าสุด
- ฟอนต์ Sarabun และ JetBrains Mono โหลดจาก Google Fonts จึงต้องมีอินเทอร์เน็ตตอนเปิดครั้งแรก ถ้าไม่มีจะใช้ฟอนต์สำรองของเครื่องแทน
